# 网课题目导出器

把学习通 / 智慧树 / 雨课堂上面的作业题目，导出成一份 Markdown 文件，方便自己离线整理复习、和同学对着题目交流。

- **只读**：只读取页面上已有的题目文字，不填答案、不提交、不会点任何提交按钮。
- 雨课堂支持**批量导出未完成作业**，自动按章节分组，一次拿到整门课。
- 页面上的题目被「字体反爬」加密（直接复制出来是乱码）时，脚本会**自动还原成正常文字**。
- 导出的文件**末尾附了一段提示词**，整份丢给 AI 就能按「题号 + 答案」的格式拿回来。

> **本项目是半自动的作业题目导出工具，仅适用于作业交流。**
> 安装浏览器插件后进入对应的学习空间，点击导出作业即可；遇到人机验证需要自己点一下，一般几分钟就完成了。

---

## 安装

1. 浏览器先装一个用户脚本管理器：[Tampermonkey](https://www.tampermonkey.net/)（油猴）。
2. 打开 [`course-question-exporter.user.js`](./course-question-exporter.user.js)，点 **Raw**，Tampermonkey 会弹出安装页，确认即可。
3. 装完刷新一次学习页面，右下角会出现按钮。

已经在用的话，脚本带 `@updateURL`，Tampermonkey 会自动检查更新，不用手动重装。

## 使用

### 一、导出当前页面的题目

打开一份作业 / 试卷页面，等题目加载完，点右下角 **「导出本页题目」**，浏览器会下载一个 Markdown 文件。

### 二、批量导出雨课堂未完成的作业

1. 进入课程 → **学习内容** 列表页（就是能看到各个章节、任务点的那一页）。
2. 点右下角 **「批量导出未完成作业」**，确认弹窗里的作业清单。
3. 脚本会逐个进入每份未完成的作业，依次点击左侧题号读取每一题，**按章节分组**导出成一个文件。

跑的过程中：

- 题目被字体加密的话，首次进入会先花 1~3 秒破解（进度会提示）。
- 如果弹出人机验证，**请手动完成**，脚本会停下等你，做完自动继续（最多等 10 分钟）。
- 全程不需要你操作页面，但**不要切走或刷新那个标签页**。

跑完后文件头会列出：作业数、总题量、题型分布、字体解密情况。如果某一章读到的题比实际题号少，会在该章下面写一行 `⚠ 题号导航共 N 题，实收 M 题；未读到的题号：…` —— 看到这行说明有题没读到，重新跑一次那一章即可。

## 导出的文件长什么样

```markdown
## 1. 第一章 中国国防

### 1. 判断题

从夏朝开始国家军队已经有固定的编制——王师。

- A. 正确
- B. 错误

### 2. 单选题

（ ）是用来测定地球的形状和大小、地球重力场的分布的卫星。

- A. 气象卫星
- B. 通信卫星
- C. 导航卫星
- D. 测地卫星
```

文件末尾的提示词会要求 AI 用 `章节号-题号. 答案` 的格式逐题作答，例如：

```
1-1. 对
1-2. 错
2-1. C
2-2. ABD
```

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 右下角没有按钮 | 页面还没加载完，刷新一次；或当前域名不在支持列表里 |
| 导出的是乱码 | 字体解密没成功。控制台执行 `__courseExport.testDecrypt()` 看解密是否可用，截图提 issue |
| 有题没导出来 | 看文件头的 `⚠` 提示行，多半是人机验证打断了切题，重跑该章即可 |
| 判断题没有选项文字 | 该平台把「对 / 错」渲染成按钮或图标，脚本会按题型补上「正确 / 错误」两项，文件头会注明 |
| 想自己排查 | 控制台执行 `__courseExport.diagnose()`、`__courseExport.scanAll()` |

## 它是怎么做的

- **抠题**：用 CSS 选择器描述「题目容器 → 题干 → 选项 → 题型」，批量取出，思路参考 [ocsjs](https://github.com/ocsjs/ocsjs) 的答题实现，但**只取不写**。
- **字体反爬**：平台会给题目下发「字形置换」字体（码点 X 的字形实际画的是另一个字 Y）。脚本把密文字用该字体渲染成位图 → 提取二值特征 → 与官方原版字体的预生成特征表做两级最近邻（16×16 粗筛 + 24×24 精排），反推每个字形真正画的是哪个字。特征表来自 [ocsjs 的公开资源](https://cdn.ocsjs.com/resources/font/font_ref_yuketang.bin)。
- **安全设计**：全程不点击任何提交类按钮；批量提交弹窗出现时脚本**绝不代点**，只提示你手动处理；导出时只在内存里翻译文本，**不回写页面 DOM**，避免误映射把你看到的页面改坏。

## 开发与测试

`test/` 下是一套离线夹具，不需要登录真实平台就能跑回归：

```bash
bash test/run-fixtures.sh                  # 跑全部夹具
bash test/run-fixtures.sh fixture-font.html  # 只跑字体解密那条
```

它会在本地起一个静态服务（`test/serve.py`，还会把 `/winfont/<file>` 映射到系统字体目录），然后用无头 Edge 打开夹具页并 dump 结果，输出形如：

```
FILE: fixture.html | TITLE: PASS:3,2,9
  题干重复行: PASS（0 处）
  选择题/判断题缺选项: PASS（0 处）
```

夹具说明：

| 文件 | 用途 |
|---|---|
| `fixture.html` | 三个平台的单页抠题回归，含题干嵌套、题干重复、判断题各种选项变体等已修过的坑 |
| `fixture-yuketang.html` | 雨课堂「批量导出未完成作业」全流程，含**模拟人机验证**打断切题的用例 |
| `fixture-font.html` | 字体解密端到端验证：用本机字体现场生成特征表并故意打乱标签来模拟字形置换 |
| `serve.py` / `run-fixtures.sh` | 本地静态服务与一键回归 |
| `gen-prompt.html` | 在真实浏览器里生成文末那段提示词，保证和脚本输出逐字节一致 |
| `repair-export.py` | 应急修复旧版（v2.1.0）导出文件里重复题干 / 缺失选项的问题 |
