# 网课题目导出器

把学习通 / 智慧树 / 雨课堂上面的作业题目导出成一份 Markdown 文件，方便自己离线整理复习、和同学对着题目交流。

**只读**：只读取页面上已有的题目文字，不填答案、不提交、不点任何提交按钮。

> 本项目是半自动的作业题目导出工具，仅适用于作业交流。
> 安装浏览器插件后进入对应的学习空间，点击导出作业即可；遇到人机验证需要自己点一下，一般几分钟就完成了。

---

## 安装

1. 浏览器先装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）。
2. 打开 [`course-question-exporter.user.js`](./course-question-exporter.user.js)，点 **Raw**，Tampermonkey 会弹出安装页，确认即可。
3. 刷新学习页面，右下角出现按钮。

## 使用

**导出当前页面的题目**：打开作业 / 试卷页，等题目加载完，点右下角 **「导出本页题目」**，浏览器会下载一个 Markdown 文件。

**批量导出雨课堂未完成的作业**：进入课程 → **学习内容** 列表页，点右下角 **「批量导出未完成作业」**，确认作业清单后脚本会逐个进入每份未完成的作业、依次点击左侧题号读取，按章节分组导成一个文件。

跑的过程中：

- 如果弹出人机验证，**请手动完成**，脚本会停下等你，做完自动继续。
- 不需要操作页面，但**不要切走或刷新那个标签页**。

跑完后文件头会列出作业数、总题量、题型分布。某一章读到的题比实际题号少时，会在该章下面写一行 `⚠ 题号导航共 N 题，实收 M 题；未读到的题号：…`，看到就重跑那一章。

## 导出的文件长什么样

```markdown
## 1. 第一章 中国国防

### 1. 判断题

从夏朝开始国家军队已经有固定的编制——王师。

- A. 正确
- B. 错误

### 2. 单选题

（ ）是用来测定地球的形状和大小、地球重力场的分布的卫星。

- A. 气象卫星
- B. 通信卫星
- C. 导航卫星
- D. 测地卫星
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 右下角没有按钮 | 页面没加载完，刷新一次；或当前域名不在支持列表里 |
| 导出的是乱码 | 平台给题目下发了「字形置换」字体（复制出来就是乱码）。刷新页面重新导出，解密失败可在控制台执行 `__courseExport.testDecrypt()` 排查 |
| 有题没导出来 | 看文件头的 `⚠` 行，多半是人机验证打断了切题，重跑该章即可 |
| 判断题没有选项文字 | 平台把「对 / 错」渲染成按钮或图标，脚本会按题型补上「正确 / 错误」两项 |

## 开发与测试

`test/` 下是一套离线夹具，不需要登录真实平台就能跑回归：

```bash
bash test/run-fixtures.sh                      # 全部夹具
bash test/run-fixtures.sh fixture-font.html    # 只跑字体解密那条
```

它会在本地起一个静态服务并驱动无头 Edge 打开夹具页，输出形如：

```
FILE: fixture.html | TITLE: PASS:3,2,9
  题干重复行: PASS（0 处）
```
